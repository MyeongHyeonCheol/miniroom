# 개선 사항 목록

작업 중 발견했지만 그 작업 범위 밖이라 미뤄 둔 개선 사항을 모은다. 버그가 아니라 "있으면 더 좋은 것", 또는 지금은 괜찮지만 나중에 손봐야 할 것이다.

- 작업 중 발견하면 바로 고치지 않고 여기에 한 줄로 추가한다(범위를 넓히지 않기 위해).
- 처리하면 줄을 지우지 않고 상태를 `완료`로 바꾸고 날짜를 적는다. 하지 않기로 하면 `안 함`과 이유.
- 우선순위: **높음**(MVP 전에 필요), **보통**(MVP 안에서 하면 좋음), **낮음**(베타 이후).
- 단계별 할 일은 개발 프로세스 문서가 기준이다. 여기 있는 항목을 하기로 하면 해당 단계 작업으로 옮긴다.
